# Phase 1 パーツ機能 チュートリアル

> 関連: 設計仕様書 [`phase1-parametric-components.md`](./phase1-parametric-components.md)

このドキュメントは Phase 1 で導入された **パーツ機能** の操作ガイドです。
キャンバスに描いた図形を「パーツ」として登録し、他のキャンバスや別ファイルで使い回すまでの一連の流れを説明します。

---

## 1. パーツとは何か

- **パーツ定義 (Part Definition)**: 図形群を 1 つの単位として登録したテンプレート。`PartDefinitions` コレクションに保存されます。
- **パーツインスタンス (Part Instance)**: パーツ定義をキャンバスに配置した実体。複数のインスタンスが 1 つの定義を共有します。
- **公開パラメータ (Exposed Property)**: 定義の中で「外部から弄れる」プロパティ。各インスタンスごとに値を持てます (Phase 1 後半で UI 整備予定)。

---

## 2. パーツを作る (Promote)

1. キャンバス上で図形を 1 つ以上選択します (矩形ツールで描いた図形などを選択ツールでクリック)。
2. 右クリック → コンテキストメニューから **「パーツ化…」** を選択。
3. ダイアログにパーツ名を入力 (空欄なら `パーツN` が自動採番) → **OK**。
4. 元の図形がキャンバスから消え、代わりに「パーツ」というラベルの付いた半透明矩形 (PartInstance) が配置されます。

> パーツ化された瞬間、選択していた図形はパーツ定義の中に **クローンとして** 保存されます。元の図形オブジェクトは破棄されますが、定義側のクローンは独立しているので影響を受けません。

### Undo 動作
- パーツ化を **Ctrl+Z (Undo)** で元に戻すと、`PartDefinitions` から該当定義が消え、元の図形がキャンバスに復元されます (孤児定義は残りません)。

---

## 3. パーツの中身を編集する (PartEditor)

1. キャンバス上の PartInstance を **ダブルクリック** すると **パーツ編集ウィンドウ** が開きます。
   - もしくは右クリック → **「パーツ定義を編集…」**
2. パーツ編集ウィンドウは以下のレイアウト:
   - **上部ツールバー**: 「矩形を追加」 / 「選択を削除」
   - **中央キャンバス**: 定義内部の図形がレンダリングされる
   - **右側プロパティパネル**: 選択中図形の Left / Top / Width / Height / EdgeThickness / 枠線色 / 塗りつぶし色 を編集

### 3.1 矩形を追加する
- 「矩形を追加」ボタンをクリックすると、座標 (50,50) サイズ 100×60 のグレー枠矩形が定義に追加されます。

### 3.2 図形を選択する
- キャンバス上の図形をクリックすると、青いハロ (`DropShadowEffect`) で選択状態が示されます。
- 選択状態になると右側プロパティパネルが表示されます。

### 3.3 図形を削除する
- 選択した状態で **Delete キー** または「選択を削除」ボタン。

### 3.4 図形をドラッグして動かす
- 図形をマウスドラッグで自由に動かせます (リアルタイム反映)。

### 3.5 位置・サイズ・枠線太さを編集する
- プロパティパネルの TextBox に値を入力 → **Tab** または別フィールドをクリックすると `LostFocus` で確定。
- 即時反映ではなく `LostFocus` なので、IME 確定や複数桁入力中の中間状態には反応しません。

### 3.6 色を編集する
- 枠線色 / 塗りつぶし色のスウォッチをクリックするとカラーピッカーダイアログが開きます。
- 色を選んで OK → 選択中図形の `EdgeBrush` / `FillBrush` に反映。

---

## 4. パーツを複製する (Clone)

1. キャンバス上の PartInstance を選択。
2. 右クリック → **「複製して新パーツとして登録」**。
3. `元のパーツ名 のコピー` (またはサフィックス番号付き) で新しいパーツ定義が作成され、パーツ編集ウィンドウが開きます。

> Clone は内部図形と公開パラメータをディープコピーします。**Undo で取り消し可能** です (孤児定義は残りません)。

---

## 5. パーツを切り離す (Detach)

- PartInstance を選択 → 右クリック → **「パーツから切り離す」**。
- インスタンスがキャンバスから消え、定義内部の図形のクローンが個別の図形としてキャンバスに展開されます。
- パーツ定義自体は削除されません (他のインスタンスがまだ使っている可能性があるため)。

---

## 6. 公開パラメータバッジ

- PartInstance の右上に青い **「公」バッジ** が表示されることがあります。
- これは「このパーツが公開パラメータを持っている (= 外部から制御可能な箇所がある)」ことを示します。
- 現状の Phase 1 では公開パラメータを編集する UI は未実装なので、Promote 直後のパーツには表示されません。将来の Phase で表示されるようになります。

---

## 7. パーツを別ファイルにエクスポート / インポート (.bgpart)

### エクスポート
1. キャンバス上の PartInstance を選択。
2. 右クリック → **「パーツをエクスポート…」**。
3. SaveFileDialog で保存先を指定 → `.bgpart` ファイルとして保存されます。
   - ファイル名のデフォルトはパーツ名 (使用不可な文字は `_` に置換)。

### インポート
1. メインメニュー **ファイル(F) → パーツをインポート… (.bgpart)** を選択。
2. OpenFileDialog で `.bgpart` ファイルを指定。
3. パーツ定義として `PartDefinitions` に追加されます。
   - **同じファイルを何度インポートしても重複しません**。Import するたびに新しい Id が振られるので、独立したパーツ定義として登録されます。
4. **Undo で取り消し可能** (Import 分の Definition が消える)。

### .bgpart ファイルの中身
```xml
<BoilersGraphicsPart Version="1">
  <PartDefinition Id="...">
    <Name>...</Name>
    <Items>
      <DesignerItem ...>...</DesignerItem>
    </Items>
    <ExposedProperties />
  </PartDefinition>
</BoilersGraphicsPart>
```

## 8. トラブルシューティング

| 症状 | 確認ポイント |
|---|---|
| パーツ化メニューがグレーアウト | 図形が選択されていない / PartInstance を選択している (再度 Promote 不可) |
| ダブルクリックしてもパーツ編集が開かない | クリックが正しく PartInstance を捉えているか確認 (選択時のハンドルが表示される位置をクリック) |
| プロパティパネルの値が反映されない | TextBox にフォーカスがある状態で Tab か別 TextBox クリック (LostFocus が必要) |
| .bgpart Import が失敗する | XML の root が `BoilersGraphicsPart` であるか確認 |
