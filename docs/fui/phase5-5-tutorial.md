# Phase 5.5 XAML アニメーション出力 チュートリアル

> 関連: 設計仕様書 [`phase5-5-xaml-export.md`](./phase5-5-xaml-export.md) (v1.0 確定)
> 前提: [`phase5-tutorial.md`](./phase5-tutorial.md) を読んで Timeline / Track / Keyframe の操作と PNG 連番書出を理解していること。

このドキュメントは Phase 5.5 で追加された **WPF Storyboard / MAUI Animation XAML 出力** 機能の操作ガイドです。`boilersGraphics` で組んだアニメをそのまま実アプリ (WPF / .NET MAUI) にコピペできる形で書き出します。

---

## 1. Phase 5.5 で追加された要素

| 機能 | UI 表記 / 場所 | 内部型 / 経路 | 用途 |
|---|---|---|---|
| WPF XAML 書出ボタン | タイムラインペインのトランスポート右側「WPF XAML...」 | `WpfXamlExportDialog` | `UserControl` + `Storyboard` の XAML + 任意で `.xaml.cs` |
| MAUI XAML 書出ボタン | 同「MAUI XAML...」 | `MauiXamlExportDialog` | `ContentView` の XAML + 必須の `.xaml.cs` (Animation API) |
| WPF Exporter | (Helper) | `WpfStoryboardXamlExporter` | `IAnimationExporter` 実装 |
| MAUI Exporter | (Helper) | `MauiAnimationXamlExporter` | 同上 |

## 2. WPF Storyboard XAML 出力

### 2.1 出力フロー

1. 図形を配置し、Timeline ペインで好きな Track / Keyframe を打つ (Phase 5 のフロー)。
2. Timeline ペインの **「WPF XAML...」** ボタンをクリック。
3. ダイアログで以下を入力:
   - **ターゲット名前空間** (例: `MyApp.Animations`)
   - **クラス名** (例: `FuiAnimation`)
   - **アクセス修飾子** (`public` / `internal`)
   - **インデント幅** (1〜8、既定 4)
   - **`.xaml.cs` を生成** チェック (既定 ON、OFF にすると `.xaml` のみ)
   - **出力ファイル**: 参照ボタンから保存ダイアログで選択
4. 「書き出し」を押すと `<選択パス>.xaml` (および必要なら `<選択パス>.xaml.cs`) が生成される。

### 2.2 出力の構造

```xml
<!-- Generated by boilersGraphics Phase 5.5 v1.0 -->
<UserControl x:Class="MyApp.Animations.FuiAnimation"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <UserControl.Resources>
        <Storyboard x:Key="MainStoryboard" RepeatBehavior="Forever">
            <DoubleAnimationUsingKeyFrames Storyboard.TargetName="Item_aaaa...." Storyboard.TargetProperty="(Canvas.Left)">
                <EasingDoubleKeyFrame KeyTime="0:0:0" Value="50">
                    <EasingDoubleKeyFrame.EasingFunction>
                        <SineEase EasingMode="EaseInOut" />
                    </EasingDoubleKeyFrame.EasingFunction>
                </EasingDoubleKeyFrame>
                <LinearDoubleKeyFrame KeyTime="0:0:2" Value="400" />
            </DoubleAnimationUsingKeyFrames>
        </Storyboard>
    </UserControl.Resources>
    <UserControl.Triggers>
        <EventTrigger RoutedEvent="UserControl.Loaded">
            <BeginStoryboard Storyboard="{StaticResource MainStoryboard}" />
        </EventTrigger>
    </UserControl.Triggers>
    <Canvas>
        <Rectangle x:Name="Item_aaaa...."
                   Canvas.Left="50" Canvas.Top="100"
                   Width="80" Height="40"
                   Stroke="#FF000000" StrokeThickness="1"
                   Fill="#FFFF0000" />
    </Canvas>
</UserControl>
```

対応する code-behind (`.xaml.cs`、デフォルト ON):

```csharp
// Generated by boilersGraphics Phase 5.5 v1.0
using System.Windows.Controls;
using System.Windows.Media.Animation;

namespace MyApp.Animations;

public partial class FuiAnimation : UserControl
{
    public FuiAnimation()
    {
        InitializeComponent();
    }

    public void BeginAnimation()
    {
        var sb = (Storyboard)FindResource("MainStoryboard");
        sb.Begin(this, true);
    }

    public void StopAnimation()
    {
        var sb = (Storyboard)FindResource("MainStoryboard");
        sb.Stop(this);
    }
}
```

### 2.3 主要マッピング

仕様書 §7 の確定マッピング表を抜粋:

| Phase 5 PropertyPath | WPF Storyboard.TargetProperty | アニメ要素 |
|---|---|---|
| `Left.Value` | `(Canvas.Left)` | `DoubleAnimationUsingKeyFrames` |
| `Top.Value` | `(Canvas.Top)` | 同上 |
| `Width.Value` / `Height.Value` | `Width` / `Height` | 同上 |
| `RotationAngle.Value` | `(UIElement.RenderTransform).(RotateTransform.Angle)` | 同上 |
| `EdgeThickness.Value` | `StrokeThickness` | 同上 |
| `EdgeBrush.Value` | `(Shape.Stroke).(SolidColorBrush.Color)` | `ColorAnimationUsingKeyFrames` |
| `FillBrush.Value` | `(Shape.Fill).(SolidColorBrush.Color)` | 同上 |
| `GlowRadius.Value` | `(UIElement.Effect).(DropShadowEffect.BlurRadius)` | `DoubleAnimationUsingKeyFrames` |
| `GlowIntensity.Value` | `(UIElement.Effect).(DropShadowEffect.Opacity)` | 同上 |
| `GlowColor.Value` | `(UIElement.Effect).(DropShadowEffect.Color)` | `ColorAnimationUsingKeyFrames` |

イージング 12 種は WPF 標準と 1:1 同名対応 (`SineEase` / `CubicEase` / `BounceEase` 等)。`LinearEase` のみ `EasingFunction=null` (= `LinearDoubleKeyFrame` / `LinearColorKeyFrame` を採用)。

### 2.4 図形のマッピング

| 図形 | WPF 出力要素 |
|---|---|
| `NRectangleViewModel` | `<Rectangle>` |
| `NEllipseViewModel` | `<Ellipse>` |
| `NPolygonViewModel` | `<Polygon Points="...">` (PathGeometry が直線セグメントのみ) / `<Path Data="...">` (曲線含む) |
| `PathDesignerItemViewModel` / `OrthogonalConnectorViewModel` / `AnchorBezierConnectorViewModel` / `PolyBezierViewModel` | `<Path Data="...">` |
| `StraightConnectorViewModel` | `<Line>` |
| `LetterDesignerItemViewModel` | `<TextBlock>` |

テキスト系 (`MonoText` / `DataGen` / `NumSeq` / `TextMatrix` / `TextOnPath`) は Phase 5.5 範囲外 (将来枠)。

## 3. MAUI Animation XAML 出力

### 3.1 出力フロー

1. WPF と同じく Timeline ペインで Track / Keyframe を組む。
2. **「MAUI XAML...」** ボタンをクリック。
3. ダイアログ:
   - ターゲット名前空間 / クラス名 / アクセス修飾子 / インデント幅 / ヘッダコメント / 出力ファイル
   - **`.xaml.cs` を生成チェックは無い**: MAUI の Animation API はコード側必須なので常に両方出力。
4. 「書き出し」で `<選択パス>.xaml` と `<選択パス>.xaml.cs` の 2 ファイルが生成される。

### 3.2 出力の構造

**XAML (`.xaml`)**:

```xml
<!-- Generated by boilersGraphics Phase 5.5 v1.0 -->
<ContentView x:Class="MyApp.Animations.FuiAnimation"
             xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml">
    <ContentView.Content>
        <AbsoluteLayout>
            <Rectangle x:Name="Item_aaaa...."
                       AbsoluteLayout.LayoutBounds="50,100,80,40"
                       AbsoluteLayout.LayoutFlags="None"
                       Stroke="#FF000000" StrokeThickness="1"
                       Fill="#FFFF0000" />
        </AbsoluteLayout>
    </ContentView.Content>
</ContentView>
```

**Code-behind (`.xaml.cs`)**:

```csharp
// Generated by boilersGraphics Phase 5.5 v1.0
using System;
using Microsoft.Maui.Controls;
using Microsoft.Maui.Controls.Shapes;
using Microsoft.Maui.Graphics;

namespace MyApp.Animations;

public partial class FuiAnimation : ContentView
{
    public FuiAnimation()
    {
        InitializeComponent();
        Loaded += (s, e) => BeginAnimation();
    }

    public void BeginAnimation()
    {
        StopAnimation();
        // Track 0 :: Item_aaaa.... Left
        var __parent_0_Left = new Animation();
        __parent_0_Left.Add(0, 1, new Animation(
            d => { var __b = AbsoluteLayout.GetLayoutBounds(Item_aaaa....); AbsoluteLayout.SetLayoutBounds(Item_aaaa...., new Rect(d, __b.Y, __b.Width, __b.Height)); },
            50, 400, Easing.SinInOut));
        __parent_0_Left.Commit(this, "Item_aaaa...._Left_anim_0", length: 2000u, easing: Easing.Linear, repeat: () => true);
    }

    public void StopAnimation()
    {
        this.AbortAnimation("Item_aaaa...._Left_anim_0");
    }
}
```

> ⚠️ `Item_aaaa....` は実際には `Item_<Guid:N>` 形式の長い名前になります。XAML の `x:Name` と一致する識別子が `.xaml.cs` で参照される仕組みです。

### 3.3 イージングマッピング (仕様書 Q-5)

| Phase 5 EasingKind | MAUI 標準で表現可能 | カスタム ラムダ |
|---|---|---|
| `LinearEase` | `Easing.Linear` (mode 無関係) | — |
| `SineEase` / `CubicEase` | `Easing.{Sin,Cubic}{In,Out,InOut}` 全 3 モード | — |
| `BounceEase` In/Out | `Easing.BounceIn` / `Easing.BounceOut` | InOut のみ `BoilersBounceOut` ヘルパが必要 |
| `BackEase` In/Out | `Easing.SpringIn` / `Easing.SpringOut` (近似) | InOut のみカスタム |
| `QuadraticEase` / `QuarticEase` / `QuinticEase` / `ExponentialEase` / `CircleEase` / `PowerEase` / `ElasticEase` | — | 全モードで `new Easing(t => ...)` |

カスタム必要なものが含まれていると、Phase 5 の `EasingFunctions` core formula と一致するラムダが `.xaml.cs` に inline 展開されます。`BounceEase` InOut が登場する場合のみ `private static double BoilersBounceOut(double t)` ヘルパも自動的に末尾に追加されます。

### 3.4 図形のマッピング (MAUI)

| 図形 | MAUI 出力要素 |
|---|---|
| `NRectangleViewModel` | `<Rectangle>` (Microsoft.Maui.Controls.Shapes) |
| `NEllipseViewModel` | `<Ellipse>` |
| `NPolygonViewModel` | `<Polygon Points="...">` / `<Path Data="...">` |
| Path 系 (Path / Orthogonal / AnchorBezier / PolyBezier) | `<Path Data="...">` |
| `StraightConnectorViewModel` | `<Line>` |
| `LetterDesignerItemViewModel` | `<Label>` (FontAttributes / TextColor / Rotation に変換) |

配置は `AbsoluteLayout.LayoutBounds="x,y,width,height"` 一括値。複数の Track が同時に Left/Top/Width/Height を動かしても破壊しないよう、コードビハインドの callback は毎フレーム `AbsoluteLayout.GetLayoutBounds` で現在の Rect を読んでから該当成分のみを書き戻す方式になっています。

### 3.5 プロパティマッピング (仕様書 §7、MAUI 列)

| Phase 5 PropertyPath | MAUI 対象プロパティ | callback テンプレ |
|---|---|---|
| `Left.Value` / `Top.Value` | `AbsoluteLayout.LayoutBounds` の X/Y 成分 | `AbsoluteLayout.SetLayoutBounds(...)` 経由 |
| `Width.Value` / `Height.Value` | `WidthRequest` / `HeightRequest` | `target.Xxx = d;` |
| `RotationAngle.Value` | `Rotation` (直接プロパティ、`RotateTransform` 不要) | 同上 |
| `EdgeThickness.Value` | `StrokeThickness` | 同上 |
| `EdgeBrush.Value` / `FillBrush.Value` | `Stroke` / `Fill` (Brush) | `target.Xxx = new SolidColorBrush(c);` (Color 補間) |
| `GlowRadius.Value` | `Shadow.Radius` | Shadow が non-null のときのみ書き換え |
| `GlowIntensity.Value` | `Shadow.Opacity` | 同上 (float キャスト) |
| `GlowColor.Value` | `Shadow.Brush.Color` | 同上 (SolidColorBrush 再生成) |

Color 系 (`EdgeBrush` / `FillBrush` / `GlowColor`) は Animation API が double 1 次元しか直接補間できないため、コードビハインドに `private static Color LerpColor(Color from, Color to, double d)` ヘルパが自動展開され、callback 内で `var c = LerpColor(fromColor, toColor, d);` のパターンで Color を再構築します。Color track が存在しないときはこのヘルパは出力されません。

## 4. サンプル: 「左右に往復しながら赤→青に色変化する矩形」

### 4.1 boilersGraphics 側のセットアップ

1. NRectangle を 1 個配置: Left=50, Top=100, Width=80, Height=40。EdgeBrush=黒、FillBrush=赤、EdgeThickness=1。
2. Timeline ペインで Duration=2.0、Fps=30、Loop チェックを入れる。
3. プロパティダイアログで `Left.Value` の ◇ をクリック (Time=0、Value=50)。
4. Timeline.Now を 2.0 に進めて、`Left.Value` を 400 に変更してから再度 ◇ (Time=2、Value=400)。Track 内 2 つ目のキーフレームに対し、EasingKind=SineEase / EasingMode=EaseInOut を指定 (現状ダイアログから直接設定する UI は未配備、内部 IR で確認)。
5. 同様に `FillBrush.Value` で Time=0 に赤、Time=2 に青のキーフレームを打つ。

### 4.2 WPF XAML 出力 (省略形)

`WPF XAML...` ボタン → クラス名 `SpinExample`、出力先 `C:\samples\SpinExample.xaml` を指定して書き出し:

`.xaml`:
```xml
<UserControl x:Class="MyApp.Animations.SpinExample" xmlns="..." xmlns:x="...">
    <UserControl.Resources>
        <Storyboard x:Key="MainStoryboard" RepeatBehavior="Forever">
            <DoubleAnimationUsingKeyFrames Storyboard.TargetName="Item_..." Storyboard.TargetProperty="(Canvas.Left)">
                <LinearDoubleKeyFrame KeyTime="0:0:0" Value="50" />
                <EasingDoubleKeyFrame KeyTime="0:0:2" Value="400">
                    <EasingDoubleKeyFrame.EasingFunction>
                        <SineEase EasingMode="EaseInOut" />
                    </EasingDoubleKeyFrame.EasingFunction>
                </EasingDoubleKeyFrame>
            </DoubleAnimationUsingKeyFrames>
            <ColorAnimationUsingKeyFrames Storyboard.TargetName="Item_..." Storyboard.TargetProperty="(Shape.Fill).(SolidColorBrush.Color)">
                <LinearColorKeyFrame KeyTime="0:0:0" Value="#FFFF0000" />
                <LinearColorKeyFrame KeyTime="0:0:2" Value="#FF0000FF" />
            </ColorAnimationUsingKeyFrames>
        </Storyboard>
    </UserControl.Resources>
    <UserControl.Triggers>
        <EventTrigger RoutedEvent="UserControl.Loaded">
            <BeginStoryboard Storyboard="{StaticResource MainStoryboard}" />
        </EventTrigger>
    </UserControl.Triggers>
    <Canvas>
        <Rectangle x:Name="Item_..." Canvas.Left="50" Canvas.Top="100" Width="80" Height="40" Stroke="#FF000000" StrokeThickness="1" Fill="#FFFF0000" />
    </Canvas>
</UserControl>
```

これを WPF アプリの `MainWindow.xaml` に貼り込めば、`UserControl.Loaded` 時点で Storyboard が自動再生されます。`BeginAnimation()` / `StopAnimation()` を `.xaml.cs` 経由で手動制御することも可能です。

### 4.3 MAUI Animation XAML 出力

`MAUI XAML...` ボタンで同じ Timeline を MAUI 形式で書き出し:

`.xaml`:
```xml
<ContentView x:Class="MyApp.Animations.SpinExample" xmlns="http://schemas.microsoft.com/dotnet/2021/maui" xmlns:x="...">
    <ContentView.Content>
        <AbsoluteLayout>
            <Rectangle x:Name="Item_..." AbsoluteLayout.LayoutBounds="50,100,80,40" AbsoluteLayout.LayoutFlags="None" Stroke="#FF000000" StrokeThickness="1" Fill="#FFFF0000" />
        </AbsoluteLayout>
    </ContentView.Content>
</ContentView>
```

`.xaml.cs`:
```csharp
using System;
using Microsoft.Maui.Controls;
using Microsoft.Maui.Controls.Shapes;
using Microsoft.Maui.Graphics;

namespace MyApp.Animations;

public partial class SpinExample : ContentView
{
    public SpinExample()
    {
        InitializeComponent();
        Loaded += (s, e) => BeginAnimation();
    }

    public void BeginAnimation()
    {
        StopAnimation();
        // Track 0 :: Item_... Left
        var __parent_0_Left = new Animation();
        __parent_0_Left.Add(0, 1, new Animation(
            d => { var __b = AbsoluteLayout.GetLayoutBounds(Item_...); AbsoluteLayout.SetLayoutBounds(Item_..., new Rect(d, __b.Y, __b.Width, __b.Height)); },
            50, 400, Easing.SinInOut));
        __parent_0_Left.Commit(this, "Item_..._Left_anim_0", length: 2000u, easing: Easing.Linear, repeat: () => true);

        // Track 1 :: Item_... FillBrush
        var __parent_1_FillBrush = new Animation();
        __parent_1_FillBrush.Add(0, 1, new Animation(d => {
            var c = LerpColor(Color.FromArgb("#FFFF0000"), Color.FromArgb("#FF0000FF"), d);
            Item_....Fill = new SolidColorBrush(c);
        }, 0, 1, Easing.Linear));
        __parent_1_FillBrush.Commit(this, "Item_..._FillBrush_anim_1", length: 2000u, easing: Easing.Linear, repeat: () => true);
    }

    public void StopAnimation()
    {
        this.AbortAnimation("Item_..._Left_anim_0");
        this.AbortAnimation("Item_..._FillBrush_anim_1");
    }

    private static Color LerpColor(Color from, Color to, double d)
    {
        return Color.FromRgba(
            from.Red + (to.Red - from.Red) * d,
            from.Green + (to.Green - from.Green) * d,
            from.Blue + (to.Blue - from.Blue) * d,
            from.Alpha + (to.Alpha - from.Alpha) * d);
    }
}
```

MAUI ContentPage で `<local:SpinExample />` を貼ると、`Loaded` イベントで両 Track が同時に commit され、`Loop=true` なので無限ループ再生されます。

## 5. 既知の制約 / 将来枠

- **テキスト系図形** (`MonoTextBlock` / `DataGeneratorTextBlock` / `NumberSequenceBlock` / `TextMatrixBlock` / `TextOnPathBlock`) は Phase 5.5 範囲外 (Q-8)。`LetterDesignerItemViewModel` のみ簡易対応。
- **`PartInstance` の `ExposedProperties` Binding** は再現されない (Q-9): 展開後の `RenderedItems` をフラット化して出す。
- **`PlayRangeStart != 0` の出力**: Storyboard の `BeginTime` には反映されない (Q-6)。全 Track の `Duration` を上限として 1 つの Storyboard を出力。
- **`ResourceDictionary` 形式**: 第一形式は `UserControl` / `ContentView`、再利用パターンは将来枠 (Q-2)。
- **`DynamicResource` テーマ切替**: Phase 4 で組んだテーマは「現時点の値」として埋め込まれる (Q-10)。
- **MAUI VisualStateManager / Triggers**: Animation API ベースのみ (Q-12)。
- **MP4 / Lottie 出力**: `IAnimationExporter` 枠組みは整っているが、Phase 5.5 範囲外。
